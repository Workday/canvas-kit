# Fonts

Canvas Kit doesn't include fonts by default. Which font you need, and how to load it, depends on
whether your application has the [Sana Canvas theme](#sana-sans) (`data-theme="sana-canvas"`)
enabled.

- If the Sana Canvas theme **is** enabled, use [Sana Sans](#sana-sans).
- If the Sana Canvas theme **is not** enabled (the default/legacy Canvas theme), configure your app
  to use [Roboto](#roboto) instead.

## Sana Sans

Sana Sans should be applied whenever the
[Sana Canvas theme](#using-sana-sans-with-the-sana-canvas-theme) is enabled in your application.

### Installation

```sh
yarn add @workday/canvas-kit-react
```

### Usage

The `fonts` module, exported from `@workday/canvas-kit-react`, makes importing font files simple so
you know you're using the correct font in your environment. We use Sana Sans for most languages we
support at Workday.

> Note: If your application environment already provides Sana Sans, you don't need to inject it as
> in the example below. Otherwise, follow these steps to inject it.

You can inject our CSS `@font-face` styles into your application by using `injectGlobal`. We prefer
this approach over `@emotion/react`'s [Global](https://emotion.sh/docs/globals) component that
injects the styles at runtime.

```ts
import {fonts} from '@workday/canvas-kit-react/fonts';
import {injectGlobal} from '@workday/canvas-kit-styling';
import {system} from '@workday/canvas-tokens-web';

injectGlobal({
  ...fonts,
  'html, body': {
    fontFamily: system.fontFamily.default,
    margin: 0,
    minHeight: '100vh',
  },
});
```

### Hosting Fonts

We currently host Sana Sans on AWS S3, and the `fonts` module includes `@font-face` rules to connect
the proper font files.

### Variable Fonts

Sana Sans is a
[variable font](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Fonts/Variable_fonts). That
means instead of importing multiple static files, you can import a single, dynamic file that
supports multiple font weights and styles. It also provides more flexibility and customization than
traditional, static fonts. But you should be able to use it identically to how you've been using
other fonts.

- **Family**: Sana Sans VF
- **Format**: TrueType variable font
- **Weight range**: 100–700 (Regular through Bold)
- **Styles**: normal, italic
- **Source**: `https://design.workdaycdn.com/assets/fonts/Sana-Sans/SanaSansLCG05-Variable.ttf`

### Monospace Font

The `fonts` module also includes IBM Plex Mono, used for `system.fontFamily.mono` under the Sana
Canvas theme.

- **Family**: IBM Plex Mono
- **Format**: WOFF2
- **Weight**: 400 (Regular)
- **Styles**: normal
- **Source**: `https://design.workdaycdn.com/assets/fonts/IBM-Plex-Mono/IBMPlexMono-Regular.woff2`

### Using Sana Sans with the Sana Canvas Theme

The Sana Canvas theme is enabled by setting `data-theme="sana-canvas"` on `<html>` (or a scoped
ancestor element). This switches the `--cnvs-sys-font-family-default` token
(`system.fontFamily.default`) to reference `'Sana Sans VF'` via the cascade in
`@workday/canvas-tokens-web/css/sana/_variables.css`.

To use this theme, you also must import `@workday/canvas-tokens-web/css/sana/_variables.css` in
addition to the other token CSS files. See the
[Getting Started guide](https://workday.github.io/canvas-kit/?path=/docs/guides-getting-started--docs)
for a full tokens CSS file import example.

> **Note:** This requires `@workday/canvas-tokens-web` `4.4.0` or later. If you're on an older
> version, upgrade `@workday/canvas-tokens-web` first.

Once the theme's font-family token and the loaded `@font-face` share the same family name, no
additional CSS override is required — import and use the `fonts` module exactly as described in
[Usage](#usage) above, and Sana Sans will render automatically wherever `data-theme="sana-canvas"`
is set.

## Roboto

If your application doesn't have the Sana Canvas theme enabled, install
`@workday/canvas-kit-react-fonts` to load Roboto instead. This module also includes Roboto Mono,
used for `system.fontFamily.mono`.

### Installation

```sh
yarn add @workday/canvas-kit-react-fonts
```

### Usage

```ts
import {fonts} from '@workday/canvas-kit-react-fonts';
import {injectGlobal} from '@workday/canvas-kit-styling';
import {system} from '@workday/canvas-tokens-web';

injectGlobal({
  ...fonts,
  'html, body': {
    fontFamily: system.fontFamily.default,
    margin: 0,
    minHeight: '100vh',
  },
});
```
