# Agent Skills

Canvas Kit ships a **consumer-facing** skill set for AI coding agents (Cursor, Claude, Copilot, and
similar tools). Each skill is a `SKILL.md` file under [`skills/`](../../../../skills/README.md) in
this repository. Agents load them to write, style, migrate, and review UI that follows Canvas Kit
correctly.

These skills target the **current generation**: Canvas Kit **v16** +
`@workday/canvas-tokens-web` **4.4** (Sana Canvas theme). They do **not** cover maintainer-only
concerns (`system.legacy.*` in `modules/**/lib/**`, Chromatic class twins, publishing) — see
[`AGENTS.md`](../../../../AGENTS.md) and [`STYLE.md`](../../../../STYLE.md) for that workflow.

## Installing skills

Copy or symlink the [`skills/`](../../../../skills/) directory into your editor's skills location
(for example `.cursor/skills/` or `.claude/skills/`), or point your agent configuration at the
folder in a checkout of this repo.

Start every version-sensitive task with the **Version Detection** skill so tables from other skills
match what's installed in `node_modules`.

## How skills depend on each other

Run **Version Detection** first whenever another skill's guidance might be release-specific.

```
version → tokens, styling, component-selection, icons, migration, review
tokens → styling, design-principles, accessibility, builder, review
component-selection → accessibility, icons, review
accessibility → design-principles, builder, review
styling → builder, review
design-principles → builder, review
migration → review
```
