# Form Validation with React Hook Form and Yup

Accessible form validation is not a library feature. It is a composition of **labels**, **error text
tied to the field**, **`aria-invalid`**, and **keyboard focus**. Canvas Kit
[`FormField`](?path=/docs/components-inputs-form-field--docs#accessibility) owns the first three
when you use its subcomponents. The application owns when validation runs and where focus goes after
submit.

1. **Identify every field, including required ones** Set `autoComplete` with a
   [standard token](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#autofill)
   when the field collects a known personal data type (`username`, `current-password`, `email`,
   `name`). That supports
   [WCAG 1.3.5 Identify Input Purpose](https://www.w3.org/WAI/WCAG22/Understanding/identify-input-purpose.html).
2. **Move focus to the first invalid field after submit** Failed submit must not leave focus on the
   submit button. Keyboard and screen-reader users need to land on the first field that is still
   invalid, in **DOM order**.
3. **Choose when to validate** Prefer validating **on submit**, then on **blur / touched** for
   fields the user has already visited (`mode: 'onTouched'` in this example). Validating on every
   keystroke while the field is still incomplete is noisy and can announce `aria-invalid` too early.
   (Relevant criteria:
   [3.3.1 Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html),
   [3.3.3 Error Suggestion](https://www.w3.org/WAI/WCAG22/Understanding/error-suggestion.html).)
4. **Do not use a live region for every field error** Field errors belong on the field
   (`aria-invalid` + `aria-describedby`). They are announced when the field **receives focus**. A
   page-level live region that restates every invalid field on submit is easy to overdo. Live
   announcements cannot be replayed, can interrupt, and have uneven support. If you add a form-level
   summary, keep it short, do not duplicate every message, and read
   [ARIA Live Regions](?path=/docs/guides-accessibility-aria-live-regions--docs) first.

This example wires `FormField`, `TextInput`, `Select`, and `InputGroup` to
[React Hook Form](https://www.react-hook-form.com/) with [Yup](https://github.com/jquense/yup). The
same practices apply if you use Formik, a server round-trip, or hand-rolled state.
