# Form Validation with React Hook Form and Yup

This example wires Canvas Kit `FormField`, `TextInput`, and `Select` to React Hook Form with Yup
schema validation. On a failed submit, focus moves to the first invalid field so keyboard and
screen-reader users are guided to the first error in the form.
