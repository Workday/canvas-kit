# Canvas Kit Density Examples

Canvas Kit does not ship a density system. Forms often still need compact, default, and
comfortable spacing. This example shows how to style Canvas Kit form elements with
`createStencil` to get three densities.

Density in this demo changes:

- **Input height and padding** (`system.size.sm` / `md` / `md + 4px`)
- **Label and input type** (`subtext.medium` / `subtext.large` / `body.small`)
- **Space between fields** (`system.gap.md` / `lg` / `xl`)
- **Space between a label and its input** (tighter when labels are vertical)

| Density | Input height | Field spacing | Type |
| ------- | ------------ | ------------- | ---- |
| High    | 32px         | 16px          | `subtext.medium` |
| Medium  | 40px         | 24px          | `subtext.large` |
| Low     | 48px         | 32px          | `body.small` |

`Switch` does not expose a size API, so its dimensions stay the same across densities. Only its
label type and surrounding field spacing change.
