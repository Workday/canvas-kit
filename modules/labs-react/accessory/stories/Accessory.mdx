# Canvas Kit Accessory

`Accessory` is a presentational tile shell for a leading visual. Prefer `AccessoryIcon`,
`AccessoryFile`, or `AccessoryMedia`, which each extend the shared `Accessory` props (`size`,
`color`, `background`) and render that shell. Accessories are decorative and always hidden from
assistive technology. They do not handle clicks or focus.

## Installation

```sh
yarn add @workday/canvas-kit-labs-react
```

## Usage

### Basic Example

`AccessoryIcon` renders a system icon in an accessory tile. Glyph size follows `size` through the
icon `data-part` on `accessoryStencil`.

<ExampleCodeBlock code={Basic} />

### Media

`AccessoryMedia` fills the tile with an image. The image stays hidden until it loads. Pass `icon`
to center a glyph on a contrast scrim.

<ExampleCodeBlock code={Media} />

### File

`AccessoryFile` renders a file type through the shared icon graphic. Colored types keep their accent
fill at every size. `file` and `txt` use `surface.alt` and a default border. `empty` is a shimmer
placeholder.

<ExampleCodeBlock code={File} />

### Media with an icon

Pass `icon` to `AccessoryMedia` to center a decorative icon on a contrast scrim. `objectFit` is
`cover` by default. `contain` fits the whole image inside the tile.

<ExampleCodeBlock code={Custom} />

### Custom color

`variant` is a stencil modifier on `AccessoryIcon`. `color` and `background` are shared `Accessory`
props and override the variant through stencil vars on the shell. Glyph size follows `size` via the
icon `data-part`. The icon is smaller than the tile: `extraSmall` is 10px, `small` is 12px,
`medium` is 16px, `large` is 18px, and `extraLarge` is 20px. Variant fills stay hidden at `small`
and `extraSmall` unless `background` is set.

<ExampleCodeBlock code={CustomColor} />

### Sizes

`size` is a shared `Accessory` prop on each component. `extraLarge` (40px) is the default.

<ExampleCodeBlock code={Sizes} />

### Variants

`variant` is set on `AccessoryIcon`. It pairs an icon color with a tile fill. The fill is painted
at `medium`, `large`, and `extraLarge`. `outline` adds a default border at those larger sizes.

<ExampleCodeBlock code={Variants} />

### Right-to-Left

The tile stays centered in right-to-left layouts. Directional icons still follow the icon's own
mirroring rules.

<ExampleCodeBlock code={RTL} />

### Accessibility

Accessory components are presentational and always `aria-hidden`. Name the item in adjacent text
instead of on the accessory. They are not buttons and do not take click or keyboard handlers.
